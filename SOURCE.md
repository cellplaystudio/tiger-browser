# Open-source code in Tiger Browser

Tiger Browser is built on open-source software: the browser at https://github.com/brave/brave-core (Mozilla Public License 2.0, version
1.100.58) and Chromium (BSD 3-Clause and others). Their notices are in the app at `tiger://credits`.

The source of every file covered by the Mozilla Public License 2.0 that Cell Play Studio changed is attached to each release on
this repository's **Releases** page (`Tiger-1.0.0-open-source.zip` for version 1.0.0). You can also ask for it at cellplaystudio@gmail.com.

Tiger's own work (its interface, media saver, dashboard, onboarding, widgets, artwork and tools) is not open source:
see `LICENSE.md`.
